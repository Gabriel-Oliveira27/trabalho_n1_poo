# Central de Eventos
## Trabalho de POO - N1

### Documento orientador olicita as seguintes :

#### Participante:

**Atributos:**

* nome;
* cpf;
* email;

#### Evento:

**Atributos:**

* nome;
* local;
* capacidadeMaxima;
* vagasDisponiveis;

#### Organizador:

**Atributos:**

* nome;
* matricula;
* cargo;

#### Inscrição:

Deve possuir:

* um **Participante**;
* um **Evento**;
* um **Organizador**;
* uma situação (**Confirmada** ou **Cancelada**).

### Para a **Main** foi solicitado:

* Criar um participante e um organizador;
* Criar pelo menos 3 eventos;
* Criar uma inscrição relacionando os objetos;
* Exibir os dados da inscrição;
* Cancelar a inscrição;
* Exibir a situação da inscrição e as vagas disponíveis.


### O que foi feito "além do solicitado":

* Criar 2 organizadores;
* Inscrever-se num evento com 0 vagas disponíveis (lotado);
* Tentar cancelar uma inscrição duas vezes;
